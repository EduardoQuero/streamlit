
Cada diretório contém uma atividade independente. Entre na pasta do exercício escolhido e identifique o arquivo Python principal e o respectivo arquivo de dependências.

## Executar localmente

```bash
git clone https://github.com/EduardoQuero/streamlit.git
cd streamlit
python -m venv .venv
```

Ative o ambiente, instale as dependências do exercício e execute:

```bash
pip install streamlit
streamlit run caminho/do/aplicativo.py
```

O Streamlit abrirá a aplicação em `http://localhost:8501`.

## Objetivo

Praticar a construção de interfaces de dados, filtros, gráficos e navegação multipágina com Python e Streamlit.
